# Layout Canvas

Личный вспомогательный сервис для быстрого проектирования **структуры** страницы перед вёрсткой с помощью ИИ.

## Зачем

Словами трудно точно объяснить ИИ сложную вложенность блоков, особенно на дашбордах с десятками графиков, KPI-карточек и таблиц. Layout Canvas позволяет за несколько минут накидать каркас мышкой, увидеть его на **настоящем CSS** и одной кнопкой получить HTML-скелет, который ИИ-чат превращает в готовую вёрстку.

## Как это работает

1. На бесконечном канвасе собираются **блоки**. Есть всего два вида: **flex-контейнер** и **grid-контейнер**. Блок, лежащий прямо на канвасе, — корневой: у него задаётся ширина превью (1440 для страницы, 480 для карточки). Блок без детей служит «местом под контент» (график, таблица).
2. Каждый блок — прямоугольник с необязательной подписью. Цвет зависит от глубины вложенности и назначается сам: он только помогает видеть структуру и в экспорт не попадает.
3. У выделенного блока в панели свойств меняются:
   - свойства **контейнера**: flex (direction, wrap, justify, align, gap) или grid (columns, rows, выравнивание, gap);
   - свойства **ребёнка**: flex / width во flex-родителе, span по колонкам и строкам в grid-родителе, высота;
   - **padding**.
4. Блоки перетаскиваются прямо в превью и в панели слоёв.
5. Превью рендерится настоящими `div` с настоящими flex/grid-свойствами: что видно на экране, то и получится в CSS.
6. Кнопка «Экспорт» отдаёт HTML-скелет выделенного блока, нескольких или всех корневых блоков с инлайн-стилями и комментариями-подписями, перед ним стоит шаблон промпта:

```html
<!-- Каркас страницы. Сверстай по этой структуре, flex/grid/padding не меняй -->
<div style="display:flex; flex-direction:column; gap:16px">
  <header style="display:flex; justify-content:space-between; padding:16px"><!-- шапка --></header>
  <div style="display:grid; grid-template-columns:250px 1fr; gap:24px">
    <aside><!-- фильтры --></aside>
    <div style="display:grid; grid-template-columns:repeat(3,1fr); gap:16px"><!-- графики ×6 --></div>
  </div>
</div>
```

## Чего здесь нет (сознательно)

- Цветов, шрифтов, рамок и прочих визуальных стилей. Только flex, grid, padding и размеры.
- Свободного позиционирования мышью. Положение блока задаётся только деревом и CSS.
- Tailwind и своего формата конфига. Экспорт делается только в чистый HTML с инлайн-стилями.

## Стек

| Часть | Технологии |
|---|---|
| Фронтенд | Vue 3 (Composition API, `<script setup>`), TypeScript (strict), Vite, Pinia, SCSS (BEM), Vitest |
| Общие типы | `shared/`: типы дерева и zod-схемы валидации (используют и фронт, и бэк) |
| Бэкенд | Node.js LTS, Fastify, TypeScript, SQLite (better-sqlite3) |
| Деплой | собственный сервер: nginx (статика + прокси `/api`), systemd, HTTPS (Let's Encrypt) |

Бэкенд появляется только в конце. До этого макеты хранятся в `localStorage` и в `.json`-файлах.

