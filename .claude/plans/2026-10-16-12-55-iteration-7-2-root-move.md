# Итерация 7.2 — перемещение корневых блоков по полю за подпись

## Цель и контекст

Корневой блок двигается по полю, если тянуть за его заголовок (подпись и ширина превью над блоком).
Опора — ядро 7.1 (`dnd/drag-store.ts`, `dnd/use-canvas-dnd.ts`, порог 4px, захват указателя после порога,
`Esc`, блокировка хоткеев). Поиск приёмника, вложение корня в блок и drop с линией вставки — не здесь (7.3–7.6).

## Чеклист

- [ ] Заголовок корня помечается `data-root-handle-id` (константы `ROOT_HANDLE_ATTR`/`ROOT_HANDLE_SELECTOR`),
      `rootHandleIdFromTarget` в `node-dom.ts`; курсор `grab` на заголовке.
- [ ] Сессия перетаскивания — объединение по `kind`: `node` (как в 7.1: захват, призрак) и `root`
      (смещение точки нажатия от левого верхнего угла корня в координатах поля, без зажима — заголовок над блоком).
- [ ] Чистые функции в `dnd-geometry.ts`: `rootGrabOffset(pressWorld, canvas)`, `rootDragPosition(offset, pointer, camera)`
      (координаты поля, округление до целых px). Тесты.
- [ ] Стор: `draggingId` — только для `node`, `movingRootId`, `rootPosition` (computed по камере); `isDragging` — любой вид.
- [ ] Предпросмотр: корень рисуется в новой точке без записи в документ (`use-canvas-root.ts`: булев `isMoving`,
      стиль пересчитывается на движение только у перемещаемого корня).
- [ ] Отпускание — один `layoutStore.moveNode(id, { type: 'canvas', at })` (один шаг истории; та же точка — без шага).
      `Esc` и прочие отмены возвращают корень на место (документ не трогался).
- [ ] Оверлей выделения: при перемещении корня рамка едет вместе с ним (пересчёт по сессии), при перетаскивании узла — скрыта.
- [ ] Клик по заголовку корня выделяет корень (раньше снимал выделение — цель клика искалась только по `data-node-id`).
- [ ] DOM-тесты: тянуть за заголовок двигает корень, Esc возвращает, отпускание пишет один шаг истории (undo возвращает),
      короткий клик по заголовку выделяет корень, тело корня по-прежнему тянет узел.
- [ ] USER_GUIDE, PLAN, браузер (обе темы), коммит.

## Архитектурные решения

- **Предпросмотр без записи в документ.** Запись на каждое движение мыши засорила бы историю и автосохранение;
  документ меняется один раз при отпускании. Отмена бесплатна.
- **Позиция по указателю, а не по сумме сдвигов:** `world = screenToWorld(camera, pointer) - offset`. Пан и зум
  колесом во время перетаскивания сохраняют точку захвата под курсором.
- **Округление до целых px поля** — координаты в документе и экспорте остаются читаемыми.
- **`moveNode` на канвас, а не `updateRootPlacement`:** у последнего склейка правок одного поля за 500 мс,
  два быстрых перемещения слились бы в один шаг.
- Призрак и пунктирный след у корня не рисуются — двигается сам корень.

## Риски

- Двойной клик по заголовку (переименование) — без сдвига перетаскивание не начинается, `dblclick` работает как раньше.
- Производительность: стили неподвижных корней зависят от булева `isMoving` и не пересчитываются на движение.
