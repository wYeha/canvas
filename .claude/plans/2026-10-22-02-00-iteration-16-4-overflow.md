# 16.4 Честное переполнение + переключатель «Структура / Пропорции»

## Цель
Содержимое блока с фиксированным размером (число) и корня с фиксированной высотой превью не вылезает за рамку и не
перекрывает соседей: обрезка по краю, метка у края, бейдж «+N скрыто ↓», по клику — временно раскрыть. Переключатель
превью: «Пропорции» (числа рисуются, обрезка и метки) / «Структура» (числа игнорируются, режим размера — значком).

## Декомпозиция
- [ ] Чистая `overflow.ts`: `clipAxes(node, parentKind, rootFixedHeight)` — оси обрезки (фикс. с числом; ось прокрутки не
  режем), `hiddenChildCount(box, children, axes)` — дети, вылезающие за рамку, `overflowBadgeText`.
- [ ] `node-style.ts`: `previewEntries(entries, showSizes)` — в «Структуре» без чисел размеров (кроме `0`).
- [ ] `size-mode.ts`: `sizeMarks(self)` — `↔`/`↕` у «Заполнить», `⊢360⊣` / `⊤48⊥` у «Фикс.» — для «Структуры».
- [ ] `view-settings-store`: `sizesShown` (localStorage, по умолчанию «Пропорции»), кнопка в `CanvasZoom`.
- [ ] Классы `canvas-node--clip-x|y` (overflow: clip по оси), `--overflow-x|y` (метка у края цветом ошибки).
- [ ] `use-canvas-overflow.ts` (provide/inject, подключён во viewport): после перерисовки (документ, высоты корней,
  зеркало, режим, раскрытые) замер `offset*` прямых детей у блоков с обрезкой → карта `id → {count, axis}`; раскрытые id.
- [ ] `CanvasNode`: бейдж-кнопка в слое подписи (`pointer-events: auto`, `keepFocusOnMouseDown`), клик — раскрыть/свернуть.
- [ ] Корень с фиксированной высотой превью — обрезка по высоте (проп `rootFixedHeight` из `CanvasRoot`); в «Структуре» высота
  корня не задаётся.
- [ ] Тесты: чистые функции, DOM-тест бейджа (подмена `offset*`), снапшоты не меняются (экспорт не трогаем).
- [ ] USER_GUIDE, TOKENS, DESIGN, PLAN.

## Риски
- Замер на каждый кадр — дорого: только по событиям (watch + rAF), только блоки с обрезкой, `offset*` без зума.
- Слой подписи скрыт при выключенных подписях → бейдж пропадёт: скрывать чип, а не слой.
- Клик по бейджу выделяет блок (pointer на viewport) — допустимо; перетаскивание начинается только после порога.
- Раскрытие — состояние сеанса, не документ: в истории и экспорте его нет.
