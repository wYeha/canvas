# Этап 14 + 15.1: размеры как поведение, gap токенами

## Цель
Агенту важно, что растягивается, а что фиксировано; число — необязательная подсказка. `min-width:0` должен следовать из модели. Gap возвращается в модель токенами S/M/L (решение пользователя отменяет 8.4).

## Модель (@shared, только добавление полей — старые документы валидны без миграции)
- `self.widthMode?`, `self.heightMode?`: `'fill' | 'fixed'`. Нет поля — по содержимому; но если задано `width`/`height` — это «фиксированный с числом» (так старые значения автоматически становятся фиксированными — «миграция» без переписывания данных).
- `self.minWidth?`, `self.maxWidth?` — безопасные CSS-строки (14.2).
- `container.gap?`: `'s' | 'm' | 'l'` (нет поля — без зазора: так старые документы и экспорт не меняются). Новые блоки — `'m'` (прежнее «16 у всех»).
- `canvas.fullScreen?: boolean` у корня (14.3), по умолчанию false.

## Стили (node-style.ts — один источник для превью и экспорта)
`styleEntries(node, parentKind, parentDirection = 'row')`. Главная ось flex-родителя: row/row-reverse — ширина, column/column-reverse — высота.
- flex-родитель, главная ось: fill → `flex:1 1 0` + `min-width:0`/`min-height:0`; fixed с числом → `flex:none` + размер; fixed без числа → `flex:none` (+ намерение в комментарии экспорта); content → ничего.
- flex-родитель, поперечная ось: fill → `align-self:stretch`; fixed → размер (без числа — намерение); content → ничего.
- grid-родитель: fill → `justify-self:stretch` (ширина) / `align-self:stretch` (высота); fixed → размер.
- Свободное `flex` (не по умолчанию) — в «Дополнительно», перекрывает `flex` из режима.
- `min-width`, `max-width`, `min-height` — как заданы.
- gap: `gap:var(--gap-m)`; у корня вывода экспорт добавляет определения `--gap-s:8px; --gap-m:16px; --gap-l:32px` (только используемые). Превью: класс-модификатор `canvas-node--gap-s|m|l` (значения из TOKENS), без gap — редакторский минимум 4px, чтобы соседи различались.
- Корень fullScreen: превью — высота = высота превью или 900, экспорт — `height:100vh` + в заголовке «экран целиком (100vh), страница целиком не прокручивается».

## Риски
- Существующие тесты стилей с `styleEntries(node, kind)` — параметр направления необязательный, по умолчанию row.
- Старые документы: `flex: 1` в превью/экспорте не меняется (поле flex остаётся). Новый режим «Заполнить» выставляет режим и очищает конфликтующие width/flex.
- Padding контейнера токенами («по желанию» в ТЗ) не делаем: редакторский отступ 20 остаётся, в экспорт не идёт — отметить в PLAN.
