Описание проекта: [README.md](README.md). План с чеклистом: [docs/PLAN.md](docs/PLAN.md). Дизайн-решения: [docs/DESIGN.md](docs/DESIGN.md), значения — [docs/TOKENS.md](docs/TOKENS.md). Сверяться с ними при любой UI-работе. Договорённости с пользователем, порядок работы и уроки прошлых итераций для любого агента (в том числе вне Claude Code): [.claude/rules/agent-workflow.md](.claude/rules/agent-workflow.md).

## Порядок работы

- Работаем по одной итерации (`X.Y`) из `docs/PLAN.md` за раз. Делаем только её и не забегаем вперёд.
- По завершении: `npm run check` зелёный, пункт отмечен `[x]`, при отклонениях от плана оставлена заметка `> ...` под пунктом.
- **Руководство пользователя** [docs/USER_GUIDE.md](docs/USER_GUIDE.md) обновляется в каждой итерации, которая добавляет или меняет действие: как им пользоваться и все горячие клавиши. Без этого итерация не считается завершённой.
- Общение и комментарии в коде на русском.
- После каждой завершённой итерации — коммит в `main` (без push).

## Экономная схема работы (согласована с пользователем)

- **Простые итерации** (каркас, стили, вёрстка фрагментов, мелкие правки) — родитель делает сам или отдаёт одному worker с коротким заданием, **без planner**. Для таких worker-заданий модель `sonnet`.
- **Сложная логика** (1.3 дерево, 1.5–1.6 камера, этап 4 экспорт, этап 7 перетаскивание) — planner + worker на `opus`, ревью сразу после итерации.
- **Ревьюер** — один раз в конце этапа на общий diff этапа (кроме рискованных итераций выше).
- Гарантия качества между ревью — зелёный `npm run check`.
- Субагенты возвращают **короткие отчёты**: файлы, результат проверок, отклонения.
- Скиллы `superpowers:*` не использовать.
