# Руководство пользователя

Как пользоваться Layout Canvas: каждое действие и горячие клавиши.

> Сервис в разработке. Руководство описывает **целевое** поведение. Статус раздела: ⏳ — запланировано, ✅ — уже работает. Этот файл обновляется в каждой итерации, которая добавляет или меняет действие.

---

## 1. Основные понятия ⏳

- **Блок** — прямоугольник, который работает как flex- или grid-контейнер. В него можно вкладывать другие блоки. Цвет блока зависит от глубины вложенности и назначается сам: так на глаз видно, что во что вложено. В экспорт цвет не попадает.
- **Корневой блок** — блок, лежащий прямо на канвасе. У него есть **ширина превью**: ширина экрана или места, в котором этот блок будет жить (1440 для страницы, 480 для карточки). Внутренние размеры (`fr`, `%`, `flex`) считаются от неё.
- **Документ** — сохранённая работа целиком. В одном документе сколько угодно корневых блоков.

## 2. Интерфейс ⏳

| Где | Что |
|---|---|
| Хедер | Документы, статус сохранения, тема, «?» (горячие клавиши), «Выйти» (только после входа), «Экспорт» |
| Канвас | Бесконечное поле с блоками |
| «Слои» (слева сверху) | Дерево всех блоков |
| «Свойства» (справа сверху) | Настройки выделенного блока |
| Тулбар (снизу по центру) | + Flex, + Grid, «Шаблоны», отмена, повтор |
| Путь (слева снизу) | Цепочка от корневого блока до выделенного, по сегментам можно кликать |
| Зум (справа снизу) | переключатели «Показывать подписи», «Живое зеркало связей» и «Все стрелки связей», −, текущий масштаб, +, «вписать всё» |

## 3. Документы ✅

- **Открыть выпадашку:** кнопка с названием документа в хедере (слева, рядом с логотипом). В списке — название, под ним «изменён вчера · 5 корневых»; текущий документ отмечен галочкой. Самые свежие — сверху.
- **Создать:** выпадашка → «Новый документ». Появится пустой документ «Без названия» и станет текущим; предыдущий сохраняется. Переименовать его можно отдельным действием.
- **Переключиться:** выпадашка → клик по документу (или стрелки и `Enter`). Текущий документ перед этим сохраняется. История отмены, выделение и положение поля сбрасываются: поле показывает все блоки нового документа (пустой — начало).
- **Переименовать:** навести на строку → значок карандаша (или выбрать строку стрелками и нажать `F2`). Название редактируется прямо в строке: `Enter` или клик мимо — применить, `Esc` — отмена. Пустое название отменяет переименование. Переименование не входит в историю отмены (`Ctrl` + `Z` его не откатывает).
- **Удалить:** навести на строку → значок корзины (или `Delete` на выбранной строке). Строка спросит «Удалить «…»?»: «Отмена» или «Удалить». Вернуть документ после удаления нельзя. Если удалить текущий, откроется самый свежий из оставшихся, а если документов не осталось, создастся новый пустой.
- **Клавиши в выпадашке:** `↑` / `↓` — по строкам, `Enter` — выбрать, `F2` — переименовать, `Delete` — удалить, `Esc` — закрыть (в режиме правки строки — отменить правку).
- **Сохранение:** автоматическое, через полсекунды после последней правки — сначала в браузер, затем (после входа) на сервер. Индикатор в хедере:
  - «Сохраняется…» — правка записывается или отправляется на сервер;
  - «Сохранено» — документ в браузере и на сервере совпадают;
  - «Сохранено в браузере» — сервера нет (вход не выполнялся, сервер не отвечал при открытии): документы хранятся только в этом браузере;
  - «Нет связи с сервером» (красная точка) — правки сохранены в браузере, но на сервер не ушли; приложение само повторит отправку через полминуты, при возвращении на вкладку и при появлении сети;
  - «Не удалось сохранить» — не получилось записать даже в браузер (например, кончилось место). При ошибке переключиться на другой документ нельзя, пока текущий не сохранится: удалите ненужные документы и повторите правку. При запуске открывается документ, с которым вы работали последним; если документов нет, создаётся пустой «Без названия».
- **Синхронизация между устройствами:** после входа список документов — общий для всех браузеров, где вы вошли. Документы с сервера появляются в выпадашке сами (при открытии редактора и при возвращении на вкладку); удалённый на одном устройстве исчезает на других. Если открытый документ изменили на другом устройстве, а здесь он не правился, откроется свежая версия (история отмены сбросится). Если один документ правили в двух местах, остаётся более поздняя правка. Документы, созданные без сервера, отправятся на него после входа. Если сервер потерял документы (например, базу восстановили из старой копии), браузеры отправят свои копии заново. Документ больше 1 МБ на сервер не попадёт и останется только в этом браузере (статус «Нет связи с сервером»). На новом устройстве пустой «Без названия», созданный при запуске, заменяется документами с сервера, если его не успели изменить.
- **Демо (`?demo` в адресе, только в режиме разработки):** открывается временный документ, он **не сохраняется** и в список не попадает; в хедере написано «Демо, не сохраняется», выпадашка документов недоступна.
- **Сохранить в файл:** выпадашка → «Сохранить в .json». Браузер скачает текущий документ как `<название>.layout.json` (читаемый JSON с отступами). Файл можно хранить в git и переносить между компьютерами.
- **Открыть файл:** выпадашка → «Открыть .json…» → выбрать файл (до 2 МБ). Документ добавится в список **как новый** (существующий с тем же названием не перезапишется: к названию добавится « (2)»), станет текущим, история отмены сбросится, поле покажет все блоки. Если файл не открылся (не JSON, повреждён, слишком большой), внизу по центру появится сообщение «Файл не открыт: …» с причиной, пропадёт само через 5 секунд или по крестику (сообщение об ошибке само не пропадает — закрывается только крестиком); текущий документ не изменится.
- **Не хватает места при открытии файла:** если браузер не смог сохранить новый документ, он не откроется, текущий документ останется на месте, а внизу появится сообщение «Файл не открыт: не хватает места в хранилище браузера — удалите ненужные документы». Удалите ненужные документы из списка и откройте файл снова.
- **Повреждённый документ:** если сохранённый документ не читается (не проходит проверку формата), он не удаляется: просто пропадает из списка, а его данные остаются в хранилище браузера и их можно восстановить вручную.
- **Несколько вкладок:** список документов обновляется при изменениях из другой вкладки, а новая запись списка не затирает документы, добавленные в другой вкладке. Одновременно править один и тот же документ в двух вкладках не стоит: сохранится последняя запись.

## 4. Навигация по канвасу ✅

- **Двигать поле:** зажать `Пробел` (курсор станет «рукой») и тянуть левой кнопкой мыши; или тянуть средней кнопкой мыши; или крутить колесо мыши (по вертикали, `Shift` + колесо — по горизонтали); или вести двумя пальцами по тачпаду. Точки фона двигаются вместе с полем.
- **Масштаб к курсору:** `Ctrl` + колесо или щипок двумя пальцами на тачпаде. Точка под курсором остаётся на месте.
- **Масштаб по ступеням:** `Ctrl` + `=` / `Ctrl` + `-` или кнопки − / + на плашке зума. Ступени 10, 25, 50, 75, 100, 150, 200, 300, 400%; масштаб меняется относительно центра видимой области. Текущий процент — на плашке зума.
- **100%:** `Ctrl` + `0`.
- **Вписать всё:** `Shift` + `1` или кнопка с уголками на плашке зума. Все корневые блоки помещаются между панелями, масштаб не больше 100%. В пустом документе поле возвращается в начало, 100%.
- **Вписать выделенное:** `Shift` + `2`. Выделенный блок помещается между панелями с отступом (масштаб до 400%).
- ✅ **Перейти к корневому блоку:** клик по его строке в панели «Слои». Блок выделяется и встаёт по центру видимой области, масштаб не меняется. Если блок больше видимой области, он показывается с левого верхнего угла.
- В полях ввода клавиши канваса не срабатывают. Колесо над панелями прокручивает панель, а не поле; `Ctrl` + колесо масштабирует поле и над панелями. Над блоком-областью прокрутки (см. «Контейнер» → «Прокрутка») колесо прокручивает его содержимое, пока есть куда, а у края снова двигает поле.

## 5. Блоки ⏳

> Работает: «Создать» ✅, «Подпись при создании» ✅, «Выделить» ✅, «Панель «Слои»» ✅, «Изменить» ✅, «История» ✅; в «Перетащить» — перенос на поле и внутрь блоков, подсветка приёмника и линия вставки ✅, перетаскивание в «Слоях» ✅, Alt-копия на канвасе ✅, автопан у края поля ✅.

### Создать ✅
- **Новый корневой блок:** снять выделение (клик по пустому полю или `Esc` до конца) → кнопки «Flex» / «Grid» в тулбаре или клавиши `F` (flex) / `G` (grid). Блок появится в центре видимой области поля (между панелями), шириной превью 480 — другую ширину выберите в «Свойствах». Если в этой точке уже лежит корневой блок, новый встанет чуть правее и ниже.
- **Вложенный блок:** выделить блок → кнопки в тулбаре или `F` / `G`. Новый блок добавится последним ребёнком. Новый блок сразу выделяется.
- ✅ **Подпись при создании:** сразу после создания блока курсор стоит в поле подписи, которое появляется у левого верхнего угла блока (от масштаба оно не зависит). Введите название и нажмите `Enter`. `Enter` или клик мимо запишут подпись. Если оставить поле пустым или нажать `Esc`, блок получит подпись `Блок-N`: N — сквозной счётчик документа, номера не повторяются. Пока поле в фокусе, клавиши канваса (`F`, `G`, `Esc`, пробел и другие) не срабатывают.
- **Отмена и повтор** в тулбаре пока недоступны (появятся вместе с историей).

### Шаблоны ✅
- **Вставить заготовку:** тулбар → «Шаблоны» → выбрать пункт. Хоткея нет. Пункты:
  - «Ряд KPI» — flex в ряд, внутри блок «KPI» с `flex: 1` и повтором ×4;
  - «Сетка графиков 2×2» — grid на две колонки, блок «График» высотой 200px, повтор ×4;
  - «Фильтры + таблица» — колонка: ряд «Фильтры» (блок «Фильтр» ×4) и «Таблица» высотой 320px;
  - «Сайдбар + контент» — grid `250px 1fr`: «Сайдбар» (колонка «Пункт меню» ×5) и «Контент» с min-height 400px.
- **Куда:** если блок выделен — заготовка добавится в него последним ребёнком; если выделения нет — новым корневым блоком в центре видимой области (ширина превью 960, у «Сайдбар + контент» 1440; при занятой точке — со смещением, как у «+ Flex»). Вставленный блок выделяется, ввод подписи не открывается — все названия уже заданы.
- **Отмена:** вставка — один шаг истории, `Ctrl` + `Z` убирает всю заготовку целиком. Дальше блоки редактируются как обычные (повторы ×N меняются в «Свойствах» → «Как ребёнок»).

### Выделить ✅
- **Клик** по блоку выделяет самый глубокий блок под курсором, клик по заголовку корневого блока (подпись над ним) — сам корневой блок. Клик по пустому полю снимает выделение. Клик, которым вы двигали поле (`Пробел` или средняя кнопка) или тянули мышь, выделение не меняет.
- **Наведение:** блок под курсором обводится тонкой синей рамкой, рядом светлый бейдж с размером. Размер при наведении показывается и над копией повтора ×N (это размер исходного блока). Если блок на экране уже 40px (его подпись без текста) или подписи выключены, в бейдже наведения есть и подпись: `nav-item · 120×48`. Выделенный блок — толстая рамка и синий бейдж `подпись · тип · Ш×В` (размер в px поля, от масштаба не зависит).
- ✅ **Показывать подписи:** кнопка с ярлыком на плашке зума (слева от «−»; имя кнопки для скринридера всегда «Показывать подписи», нажата — подписи видны; всплывающая подсказка говорит о действии: «Скрыть подписи» / «Показать подписи»). Выключенная кнопка скрывает на канвасе чипы подписей блоков и подписи пустых блоков; заголовки корневых блоков над ними остаются (за них двигают корень), двойной клик по скрытой подписи переименование не открывает (переименовать можно в «Слоях»: двойной клик по строке или `F2`). Выбор запоминается в браузере и действует для всех документов; в документ и экспорт он не попадает. Горячей клавиши нет. Текст подписей читается на цвете блока в обеих темах (контраст не ниже 4.5:1).
- ✅ **Честное переполнение:** если у блока ширина или высота «Фикс.» с числом (или у корневого блока фиксированная высота превью), а дети в него не помещаются, на канвасе он обрезается по своему краю — содержимое не вылезает и не перекрывает соседей. У края, за которым что-то скрыто, — красная полоса, в правом нижнем углу — красный бейдж `+N скрыто ↓` (N — сколько детей не поместилось хотя бы частью; `→` — по ширине). Клик по бейджу временно раскрывает блок (бейдж становится `свернуть ↑`, второй клик снова обрезает). Раскрытие — только просмотр: в документ, историю и экспорт оно не попадает и сбрасывается при перезагрузке. Ось, по которой блок прокручивается (см. «Прокрутка»), не обрезается — её прокручивают колесом.
- ✅ **Пропорции / Структура:** кнопка с линейкой на плашке зума (после стрелок связей; нажата — «Пропорции», по умолчанию). «Пропорции» — блоки рисуются по числам размеров, переполнение обрезается с меткой. «Структура» — числа размеров (`width`, `height`, `min-*`, `max-*` и фиксированная высота превью корня) не рисуются: блоки становятся одинаковыми кирпичиками по содержимому, а режим размера показан значком после подписи: `↔` / `↕` — «Заполнить» по ширине / высоте, `⊢360px⊣` / `⊤48px⊥` — «Фикс.» (без числа — пустые скобки). Удобно, когда числа мешают читать вложенность. Выбор запоминается в браузере; в документ и экспорт не попадает.
- ✅ **Подписи по размеру на экране:** подпись подстраивается под то, каким блок виден сейчас, а не под процент масштаба. Помещается — видна целиком; не помещается — обрезается многоточием внутри блока (за его край не вылезает); блок уже 40px на экране — только значок направления (→ ↓ #), полное имя — в бейдже при наведении; узкий и высокий блок (не шире 64px и не ниже 120px на экране: рейл, боковая колонка при мелком масштабе) — подпись вертикально, вдоль высоты.
- **Путь:** плашка слева снизу показывает цепочку от корня до выделенного блока, по сегментам можно кликать; без выделения — «—».
- **К родителю:** `Esc`. На корневом блоке `Esc` снимает выделение.
- **К первому ребёнку:** `Enter`.
- **Любой блок:** клик по его строке в «Слоях» или по сегменту пути.
- ✅ **Повторённый блок (×N):** у блока с «Повтором» больше 1 (см. «Свойства» → «Как ребёнок») на канвасе сразу за ним рисуются его копии — бледные, без чипа подписи (у пустого блока подпись в копии видна, но тоже бледно). У самого блока после подписи стоит `×N`. Копии нельзя выделить по отдельности: клик, наведение, двойной клик (переименование) и перетаскивание за копию или за любой блок внутри неё относятся к исходному блоку. Рамка выделения — только у исходного блока. Блок внутрь копии не перетащить: над копией приёмником считается родитель исходного блока, и блок встанет среди его настоящих соседей. При перетаскивании за копию призрак берётся от исходного блока. У корневого блока повтора нет: «Повтор» в его свойствах отсутствует, а `×N` из импортированного файла игнорируется (корень всегда один). Чтобы канвас не тормозил, на дерево корня рисуется не больше 500 блоков в копиях: копии сверх этого предела не показываются (сами блоки остаются, а в экспорт идёт значение «Повтор» как есть).

### Панель «Слои» ✅
- Корневые блоки — верхним уровнем в порядке документа (подпись корня жирнее), внутри — их деревья с отступом по уровню вложенности. В строке: значок (flex или grid), подпись (`Без подписи`, если её нет), у повторённого блока — серый знак `×N` сразу после подписи, и тип справа. Копии повтора отдельными строками не показываются.
- **Свернуть / развернуть ветку:** шеврон слева от строки (есть только у блоков с детьми; подсказка называет блок: «Свернуть «nav»»). Свёрнутое состояние запоминается, пока открыт редактор, в документ не сохраняется.
- **Выделение:** клик по строке выделяет блок на канвасе; выделение на канвасе подсвечивает строку, раскрывает свёрнутых предков и прокручивает список к ней. Клик по корневому блоку ещё и центрирует его (см. «Навигация по канвасу»). Если в этот момент вы печатали в поле панели «Свойства», клик по строке завершает ввод (текст сохраняется в прежний блок), и `Delete` / `Backspace` сразу удаляют выбранный блок, а не стирают текст. Так же ведут себя хлебные крошки.
- **Наведение:** наведите курсор на строку — блок обведётся на канвасе; наведение на блок на канвасе подсвечивает его строку.
- ✅ **Переименовать в «Слоях»:** двойной клик по строке или `F2` после клика по строке — подпись превращается в поле с текущим текстом (выделен целиком). `Enter` или клик мимо — записать, `Esc` или пустое значение — оставить прежнюю.
- Если блоков нет — «Нет блоков».
- ✅ **Переставить в списке:** потяните строку мышью (не за шеврон и не из поля переименования). После сдвига больше 4px начинается перетаскивание: на месте строки остаётся пунктирный след, за курсором едет наклонённая карточка строки. Верхняя треть другой строки — вставка **до** неё (линия с отступом по уровню вложенности), нижняя треть — **после**, середина — **внутрь** блока (подсветка строки). Нельзя отпустить на саму перетаскиваемую строку или на её потомка: такие строки приглушены, у призрака красный контур. Отпустить — один шаг истории (`Ctrl` + `Z` отменит). `Esc` до отпускания отменяет жест. Корневые блоки меняют только порядок в списке и экспорте, не координаты на поле. Свёрнутую ветку при вставке «внутрь» автоматически не раскрываем.

### Изменить ✅

> Кнопки внизу панели «Свойства», хоткеи и переименование ✅ работают. Хоткеи не срабатывают в полях ввода, при открытом окне и пока открыт ввод подписи; удержание клавиши не повторяет удаление, дублирование, вставку.

- ✅ **Кнопки в панели «Свойства»** (внизу, видны при выделении):
  - **Выше / Ниже** — переставить среди соседей (у корневого блока — порядок среди корневых, положение на поле не меняется). У крайнего соседа кнопка недоступна, причина — во всплывающей подсказке.
  - **Дублировать** — копия встаёт сразу после оригинала (корня — правее него) и выделяется. Подписи копируются как есть.
  - **На канвас** — вложенный блок становится корневым и встаёт правее своего корня. Для корневого блока кнопка недоступна.
  - **Вынести на канвас** — вложенный блок становится корневым (правее своего корня, той же ширины, что был на поле), а на его месте остаётся связь на него (см. «Связи»). Так повторяющийся фрагмент превращается в компонент, который можно подключать в другие места. Свойства «как ребёнок» и повтор остаются у места (у связи). Один шаг истории; выделяется связь. Для корня и для связи недоступно.
  - **Удалить** — удаляет блок с содержимым.
- ✅ **Переименовать:** `F2` (поле подписи откроется с текущим текстом: в строке «Слоёв», если блок выбран кликом по строке, иначе на канвасе у блока; `Enter` или клик мимо — записать, `Esc` или пустое значение — оставить прежнюю подпись, автоподпись `Блок-N` только для нового блока), или двойной клик по подписи блока на канвасе (заголовок корневого блока над ним, чип в левом верхнем углу или подпись в центре пустого блока), или двойной клик по строке в «Слоях», или поле «Подпись» в «Свойствах».
- **Тег, flex/grid-свойства:** в панели «Свойства» (раздел 6).
- ✅ **Дублировать:** `Ctrl` + `D`. Копия встаёт сразу после оригинала.
- ✅ **Переставить среди соседей:** `Alt` + `↑` / `Alt` + `↓`.
- ✅ **Удалить:** `Del` или `Backspace`.
- ✅ **Копировать / вставить:** `Ctrl` + `C`, затем выделить место и `Ctrl` + `V`. Копия блока вместе с содержимым хранится внутри редактора (системный буфер обмена не трогается), вставляется с новыми id последним ребёнком выделенного блока, а без выделения — новым корневым блоком в центре видимой области. Если на странице выделен текст, `Ctrl` + `C` копирует его, а не блок.

### Перетащить ✅

> Работает: «Потянуть блок» ✅, «Отменить перетаскивание» ✅, «Двигать корневой блок по полю» ✅, «Сделать корневым» ✅, курсор «нельзя» ✅, «Переместить блок в другое место» ✅ (включая корневой блок-приёмник), «В «Слоях»» ✅, Alt-копия на канвасе ✅, автопан у края видимого поля ✅.

- ✅ **Потянуть блок:** зажать левую кнопку мыши на блоке на канвасе и повести мышь. Перетаскивание начинается после сдвига больше 4px (короткое движение остаётся кликом). Блок выделяется, на его месте остаётся бледный пунктирный след, а за курсором едет наклонённая копия с подписью; точка, за которую взяли блок, остаётся под курсором. Крупный блок (например, страница) уменьшен до карточки. Во время перетаскивания поле можно двигать колесом и масштабировать `Ctrl` + колесом — копия меняет размер вместе с масштабом. Рамка выделения и наведение на это время скрыты, горячие клавиши канваса (кроме `Esc`) не работают. Если тянуть корневой блок за тело, он перетаскивается как блок; чтобы просто передвинуть его по полю, тяните за заголовок (см. ниже).
- ✅ **Отменить перетаскивание:** `Esc`, не отпуская кнопку мыши. Блок остаётся на месте и выделенным. Перетаскивание отменяется и при переключении на другое окно или вкладку.
- ✅ **Двигать корневой блок по полю:** тянуть за его заголовок над блоком (подпись и ширина превью, курсор — «рука»). Блок едет за курсором поверх других корневых блоков вместе с рамкой выделения и выделяется; координаты на поле — целые px. Отпустить — блок останется в новом месте, это один шаг истории (`Ctrl` + `Z` вернёт его). `Esc` до отпускания возвращает блок на место. Во время перетаскивания поле можно двигать колесом и масштабировать `Ctrl` + колесом — точка, за которую взяли заголовок, остаётся под курсором. Порядок корневых блоков в «Слоях» и в экспорте не меняется. Двойной клик по подписи в заголовке по-прежнему переименовывает блок.
- ✅ **Сделать корневым:** потянуть вложенный блок и отпустить над пустым полем. Блок станет корневым в натуральную величину (не уменьшенной карточкой): точка, за которую его взяли, окажется под курсором, ширина превью — та, что была у блока на экране (в px поля), высота — по содержимому. Это один шаг истории (`Ctrl` + `Z` вернёт блок на прежнее место), блок остаётся выделенным и встаёт последним среди корневых в «Слоях». Работает при любом масштабе и после сдвига поля колесом во время перетаскивания. Корневой блок, который тянут за тело, над пустым полем или над самим собой просто переезжает в новую точку (ширина не меняется), как при перетаскивании за заголовок.
- ✅ **Курсор «нельзя»:** во время перетаскивания блока курсор показывает, что отпустить здесь нельзя: над панелями и хедером. Отпускание в таком месте ничего не меняет. Сам перетаскиваемый блок и его содержимое не мешают: курсор над собственным следом «видит» блок под ним.
- ✅ **Переместить блок в другое место:** потянуть блок мышью. Синяя линия с точками на концах показывает, куда он встанет; блок-приёмник подсвечивается пунктиром и лёгкой заливкой. Отпустить — один шаг истории (`Ctrl` + `Z` отменит). Если отпустить на том же месте (над своим следом), документ не меняется.
  - **Во flex-блоке** место определяется по курсору: блок встанет перед первым соседом, середину которого курсор ещё не прошёл вдоль направления блока (слева направо для `row`, сверху вниз для `column`; при `row-reverse` и `column-reverse` — зеркально), а если прошёл все — после последнего. Ровно на середине соседа — после него. Если у блока включён перенос, сначала выбирается строка (или колонка) под курсором — граница между строками проходит посередине зазора, — затем место в ней. При удержании `Alt` (копия) перетаскиваемый блок **учитывается** в расчёте места.
  - **В grid-блоке** сначала выбирается ближайший к курсору ребёнок (по расстоянию до его прямоугольника на экране), затем вставка до или после него **слева направо** — как поток по строкам сетки (строка за строкой). Пустой grid — в начало. Сам перетаскиваемый блок не учитывается: над его следом он «вернётся на своё место», и ничего не изменится. При удержании `Alt` (копия) перетаскиваемый блок **учитывается** в расчёте места — линия вставки совпадает с тем, куда встанет копия.
  - Целиться нужно в свободное место блока-приёмника (зазоры, отступы, пустые ячейки): курсор над вложенным блоком выбирает приёмником его.
  - **В другой корневой блок** — так же, как во вложенный: дотянуть до него (заголовок корневого блока тоже считается этим блоком) и отпустить.
- ✅ **Скопировать перетаскиванием (только канвас):** зажать `Alt` перед тем, как отпустить — в цель drop встанет **копия** с новыми id, исходный блок останется на месте; один шаг истории, выделяется копия. Те же правила, что у переноса. Отпустить на том же месте, что и без `Alt`, — документ не меняется. В панели «Слои» `Alt` при отпускании копию не создаёт.
- ✅ **Автопан поля:** пока вы тянете блок на канвасе, подведите курсор к краю **видимого поля** (между панелями «Слои» и «Свойства», не под панелями) — поле само сдвигается в эту сторону, чтобы можно было дотянуть до далёкой цели. Колесо и `Ctrl` + колесо во время перетаскивания по-прежнему работают.
- ✅ **В «Слоях»:** потяните строку (см. «Панель «Слои»»). Верхняя и нижняя трети строки — вставка до или после (линия с отступом по вложенности), середина — внутрь блока. `Esc` отменяет жест без записи в историю.

### История ✅
- **Отменить:** `Ctrl` + `Z` или кнопка «Отменить» (стрелка назад) в тулбаре.
- **Повторить:** `Ctrl` + `Shift` + `Z`, `Ctrl` + `Y` или кнопка «Повторить» в тулбаре.
- Кнопки неактивны, когда отменять или повторять нечего. Хранятся последние 100 шагов.
- Один шаг — одно действие: создание блока вместе с его подписью, удаление, вставка, дублирование, перенос, правка поля в панели. Быстрые правки одного и того же поля подряд (стрелки числового поля, щелчки по сегментам) с паузами меньше полсекунды склеиваются в один шаг. Самая первая правка пустого поля (например, `gap`, который ещё не задан) — отдельный шаг.
- Новое изменение после отмены стирает то, что можно было повторить.
- После отмены выделяется блок, который был выделен в момент того шага; если его больше нет — выделение снимается.
- В полях ввода `Ctrl` + `Z` отменяет набор текста в самом поле, а не шаг истории. Пока открыто окно или вводится подпись блока, хоткеи истории не работают. Открытие другого документа очищает историю.

## 6. Свойства ✅

Панель «Свойства» показывает настройки выделенного блока. Если всё не помещается, панель прокручивается. Секции сворачиваются кликом по заголовку, и редактор это запоминает.

Заголовок панели показывает значок и подпись выделенного блока, а справа его вид: `flex · ребёнок grid` или `корневой · flex`. Свёрнутая секция остаётся свёрнутой после перезагрузки страницы; по умолчанию все секции раскрыты. Если ничего не выделено, панель подсказывает: «Кликните по блоку».

- ✅ **Корневой блок** (секция «Ширина превью», только у корня):
  - **Ширина:** нажмите пресет 1920 / 1440 / 1280 / 1024 / 480 или введите своё значение в поле (px, стрелки ↑/↓ шагают по 10, Shift — по 100). Подсвечен тот пресет, что совпадает с текущей шириной. Значения меньше 1 не принимаются.
  - **Высота:** «По содержимому» (блок сам растёт по содержимому) или «Фиксированная». При переключении на фиксированную берётся текущая высота блока на канвасе (или 600, если её ещё нет), её можно поправить в появившемся поле.
  - **Экспортировать как max-width:** переключатель (клик или Space/Enter), по умолчанию выключен. Выключен: ширина превью в код не попадает, только комментарием. Включён: в коде будет `max-width: <ширина>px; margin: 0 auto` (так делают страницы с ограниченной шириной контента).
  - **Экран целиком (100vh):** переключатель для страниц-приложений, которые не прокручиваются целиком (рабочее место, чат, дашборд). В коде у корня будет `height: 100vh`, в заголовке — пометка «экран целиком… прокручиваются области внутри». Если высота превью не задана, при включении она станет 900 px, чтобы на поле было видно «экран».
  - Заголовок выделенного блока закреплён над секциями и не прокручивается вместе с ними.
- ✅ **«Блок»** (у любого блока, корневого и вложенного):
  - **подпись** — введите текст: он записывается сам, как только вы на треть секунды перестанете печатать (Enter и клик мимо записывают сразу); Esc отменяет ещё не записанную правку. Пустая подпись допустима (автоподпись «Блок-N» появится позже);
  - **описание для ИИ** — что будет внутри блока («линейный график выручки, легенда справа»). Многострочное поле: Enter переносит строку; текст записывается сам после короткой паузы в наборе, Ctrl+Enter или клик мимо записывают сразу, Esc отменяет ещё не записанную правку. Пока ввод не записан, в хедере горит «Сохраняется…»; при смене выделения, экспорте (`Ctrl` + `E`), смене документа и закрытии вкладки ввод дописывается сразу. Набор одного поля без долгих пауз — один шаг истории. Уходит в экспорт комментарием, чтобы ИИ сверстал не пустую коробку, а то, что вы имели в виду;
  - **тег** — `div`, `header`, `aside`, `main`, `section`, `nav`, `footer` (выпадающий список; буква на клавиатуре перескакивает к тегу на неё);
  - ✅ **элемент** — необязательное поле: что этот блок на самом деле (`h1`, `button`, `img`, `a`, `li`, `input`…). Начните вводить — браузер покажет список подсказок, можно вписать и своё имя (латиница, цифры, дефис; `<h1>` и заглавные приводятся к `h1`). Записывается по Enter или клику мимо, Esc отменяет, пустое поле стирает элемент. В коде у пустого блока (без детей) элемент становится тегом: `<h1><!-- Заголовок --></h1>`; элементы без содержимого (`img`, `input`, `hr`, `textarea`), незнакомые имена и элемент у блока с детьми идут пометкой в начале комментария: `<!-- img: аватар -->`. Раскладочный тег при этом не меняется;
  - внутреннего отступа (padding) в панели нет: на канвасе у каждого блока фиксированный отступ 20px (чтобы подпись не перекрывала вложенные блоки), в экспорт он не попадает. Зазор между детьми задаётся в «Контейнере».
- **«Контейнер»** (у любого блока):
  - ✅ **переключатель Flex / Grid.** При смене переносятся `align-items` (`baseline` в grid становится `stretch`) и зазор; остальные поля получают значения по умолчанию;
  - ✅ **Зазор (gap)** — между детьми: «Нет», S, M, L (8, 16, 32 px; у нового блока — M). В коде — `gap: var(--gap-m)`, а значения переменных (`--gap-m: 16px`) определяются один раз у верхнего элемента кода, поэтому ИИ видит токены, а не придуманные пиксели. Зазор выводится только у блока с двумя детьми и больше (один ребёнок с повтором ×N тоже считается за N соседей). На канвасе зазор виден в натуральную величину; у блока без зазора соседи всё равно разделены тонкой редакторской щелью 4px (в код она не идёт). Числовой gap очень старых документов при открытии становится «Нет»;
  - ✅ **Прокрутка** — «Нет», «↕ Вертик.», «↔ Гориз.»: содержимое прокручивается внутри блока (лента сообщений, длинное меню, таблица в рабочей области). В коде — `overflow-y: auto` или `overflow-x: auto`; если у блока по этой оси «Заполнить», сразу добавляется `min-height: 0` / `min-width: 0`, иначе блок вырастет по содержимому и прокрутки не будет. Прокрутке нужен ограниченный размер: «Заполнить» внутри корня «Экран целиком» или «Фикс.» с числом. На канвасе у такого блока полоса цвета глубины вдоль правого (вертикальная) или нижнего (горизонтальная) края, а если содержимое не помещается — настоящая полоса прокрутки: колесо над блоком прокручивает его. Работает и у корневого блока, и у листа. При смене Flex ↔ Grid прокрутка сохраняется;
  - ✅ **flex:** `flex-direction` (стрелки → ↓ ← ↑), `flex-wrap` (переключатель «перенос»), `justify-content` и `align-items` (иконки, CSS-значение видно во всплывающей подсказке; при направлении column иконки поворачиваются вместе с осью);
  - ✅ **grid:**
    - `grid-template-columns` — текстовое поле (моноширинный шрифт) и под ним пресеты `1fr ×2`, `×3`, `×4`, `250px 1fr`, `auto-fill` (`repeat(auto-fill, minmax(200px, 1fr))`). Пресет применяется сразу, подсвечен тот, что совпадает с текущим значением (лишние пробелы не важны). Свой текст запишется по Enter или клику мимо, Esc отменяет правку. Пустое значение и символы `; " < > { }` не принимаются: поле подсветится ошибкой, прежнее значение вернётся;
    - `grid-template-rows` — так же текстом; пусто или `auto` — строки по умолчанию;
    - ✅ **Колонки на узких экранах** — необязательно: сколько колонок остаётся при сужении экрана, по шагам (`2 → 1`; можно вводить через пробел или запятую — поле само поставит стрелки). Числа по убыванию от 12 до 1, не больше 4 шагов; пустое поле стирает. Enter или клик мимо записывает, Esc отменяет. В коде — комментарием у контейнера (у корня — в заголовке): `колонки на узких экранах: 4 → 2 → 1` (текущее число колонок подставляется впереди, если его можно посчитать). Полноценных брейкпоинтов нет: ИИ добавит media-запросы сам — промпт разрешает адаптив там, где он описан. На канвасе ничего не меняется;
    - `justify-items` и `align-items` — переключатели словами `start / center / end / stretch`.
- ✅ **«Как ребёнок»** (у вложенного блока; у корня секции нет). Справа от заголовка серая подсказка: `в flex →` (стрелка показывает направление flex-родителя) или `в grid ×N` (N колонок родителя; если число зависит от ширины, как у `auto-fill`, просто `в grid`). Поля зависят от родителя:
  - **Ширина** и **Высота** — режим, а не пиксели: что растягивается, а что нет.
    - **Авто** (по содержимому, по умолчанию) — в код ничего не пишется.
    - **Заполнить** — блок занимает свободное место. По главной оси flex-родителя (ширина в строке, высота в колонке) это `flex: 1` и сразу `min-width: 0` / `min-height: 0` (без него длинное содержимое распирает блок — писать это словами в описании больше не нужно); по другой оси — `align-self: stretch`; в grid-родителе — растяжение на всю ячейку (`justify-self` / `align-self: stretch`).
    - **Фикс.** — блок не тянется и не сжимается (`flex: none` по главной оси). Число **необязательно**: появится поле «Ширина, число» (`360`, `50%`, `calc(100% - 8px)`; Enter или клик мимо записывает). Без числа в коде будет комментарий-намерение «фиксированная ширина», с числом — `width: 360px`.
    - Под режимом серым написано, что он даст в коде. Старые документы читаются сами: заданная ширина или высота — это «Фикс.» с числом. Если в «Дополнительно» задан свободный `flex` (например, `1` из старого документа), подсказка под режимом главной оси предупреждает, что действует он, а не режим.
  - **Положение** — «Обычно» (в потоке, как соседи), «Прилипает» или «Поверх»:
    - **Прилипает** — «Сверху» или «Снизу»: блок держится у края прокручиваемой области, пока она прокручивается (заголовок группы в списке, шапка таблицы, разделитель даты в чате). В коде — `position: sticky; top: 0` (или `bottom: 0`). На канвасе работает внутри блока с прокруткой — прокрутите его колесом;
    - **Поверх** — блок лежит поверх родителя в выбранном углу (кнопки ↖ ↗ ↙ ↘, по умолчанию ↗): значок, счётчик, точка «онлайн» на аватаре. В коде — `position: absolute; top: 0; right: 0`, а родитель сам получает `position: relative`. На канвасе блок так и рисуется — в углу родителя, поверх соседей;
    - под переключателем серым написано, что попадёт в код; у корневого блока положения нет;
  - в grid-родителе: `col span` и `row span` — на сколько колонок и строк растянут блок (целое от 1; пусто или 1 — не задан);
  - всегда: **«Повтор»** — сколько раз блок повторяется (целое от 1 до 24, стрелки ↑/↓ шагают по 1; пустое поле возвращает прежнее значение, больше 24 — 24). Например, одна карточка KPI с повтором 4 — это ряд из четырёх одинаковых карточек. На канвасе блок рисуется N раз (копии бледные, см. «Выделить»), в «Слоях» у него `×N`, в экспорт он уходит один раз с пометкой `×N`. Быстрые правки поля подряд — один шаг истории. У корневого блока повтора нет (нет и самой секции). Повтор можно задать и блоку внутри повторённого: тогда копий будет N × M.
  - **Дополнительно** (раскрывашка, открыта сама, если что-то задано): свободный `flex` для нестандартных случаев (быстрые кнопки `0 1 auto / 1 / auto / none` или текст, например `0 0 280px`; он важнее режима ширины/высоты, а выбор «Заполнить» по главной оси сбрасывает его к `0 1 auto`), `min-width`, `max-width`, `min-height` — текстом.
  - Число без единицы (`120`) записывается как `120px`. Символы `; " < > { }` не принимаются: поле подсветится ошибкой, прежнее значение вернётся.
  - Поля, которые не подходят родителю (например `flex` у блока в grid), не показываются, но и не стираются: вернёте блок во flex-родитель — значения на месте. В код они не попадают.

## 7. Экспорт ✅

1. Выделите то, что нужно экспортировать (любой блок или ничего).
2. `Ctrl` + `E` или кнопка «Экспорт» в хедере.
3. В окне выберите охват:
   - **выделенный блок** вместе со всем содержимым;
   - **отмеченные корневые блоки** — галочки в списке;
   - **все корневые блоки** документа; корни, подключённые связями, отдельно не выводятся (они уже стоят на местах своих связей) и в списке не отмечены.
4. «Копировать» — код с шаблоном промпта попадёт в буфер, кнопка на 2 секунды станет зелёной «Скопировано»; окно не закрывается. «Скачать .html» — сохранить полным HTML-файлом (`имя документа.html`, для выделенного блока — `имя документа — подпись блока.html`).

В окне слева — охват, список корневых блоков с галочками (активны только при охвате «Отмеченные») и шаблон промпта; справа — предпросмотр кода с подсветкой и номерами строк, имя файла, число строк и размер. Предпросмотр только для чтения: правки вносятся на канвасе. Пока окно открыто, горячие клавиши канваса не работают; `Esc` закрывает окно.

Что попадает в код:
- flex/grid-свойства и размеры блоков в инлайн-стилях (фиксированного отступа 20px с канваса в коде нет);
- подписи и описания для ИИ в комментариях;
- повторённый блок — **один раз**, с пометкой `×N` в комментарии после подписи (`<!-- Карточка ×4 -->`) и атрибутом `data-repeat="4"` на самом элементе (в комментарии-контексте выделенного блока — «повторяется ×N»): копии с канваса в код не попадают, ИИ сам повторит элемент N раз и оформит компонентом;
- ширина превью корневых блоков в комментариях;
- на месте связи — содержимое её корня-источника целиком (с его тегом, flex/grid и детьми) со свойствами «как ребёнок» и повтором самой связи и комментарием `<!-- компонент «Карточка» -->` (с `×N`, если у связи повтор). Описания компонентов выводятся **один раз** — списком «Компоненты» в начале кода, а не на каждом месте. Ширина превью источника в код не идёт: размер задаёт место. Связи внутри источника тоже раскрываются;
- у вложенного блока — комментарий-контекст: откуда он, кто родитель, сколько места занимает.

**Шаблон промпта** (текст перед кодом) можно поменять в окне экспорта: он запоминается в браузере и общий для всех документов. Кнопка «Сбросить» возвращает текст по умолчанию. Пустой шаблон — код без промпта. В код промпт попадает первым комментарием `<!-- … -->`.

**Правила документа** — поле под шаблоном промпта в окне экспорта. Сюда пишут общие правила вёрстки именно этого документа («отступы только через gap, без margin у детей»). Они хранятся в документе (уходят вместе с ним в `.json` и на сервер), попадают в промпт отдельным абзацем «Правила документа:» после шаблона. Пустое поле — абзаца нет. Правка — шаг истории (`Ctrl` + `Z` на канвасе после закрытия окна).

## 8. Тема ✅

Переключатель солнце / луна в хедере. Выбор запоминается. Рядом — кнопка «?» с подсказкой «Горячие клавиши»: открывает окно со списком клавиш (то же, что клавиша `?`).

## 9. Вход ✅

Документы на сервере закрыты паролем (пользователь один).

- **Войти:** если сессии нет, при открытии редактора откроется страница входа. Курсор уже стоит в поле «Пароль»: введите пароль и нажмите `Enter` или «Войти». После входа откроется тот адрес, с которого вас перенаправили (например, `?demo` сохранится). Вход запоминается на 30 дней.
- **Неверный пароль:** под полем появится «Неверный пароль», поле очистится. После 10 неудачных попыток за 15 минут сервер на время перестанет принимать пароль — под полем будет «Слишком много попыток входа, попробуйте позже».
- **Сервер недоступен:** если сервер не отвечает, редактор открывается без входа и работает с документами из браузера. На странице входа в этом случае будет «Сервер недоступен, попробуйте позже».
- **Выйти:** кнопка со стрелкой из двери в хедере (подсказка «Выйти», рядом с «?»). Текущий документ перед выходом сохраняется, затем откроется страница входа. Кнопка видна только после входа: без сервера выходить не из чего.

## 10. Связи ✅

Связь подключает корневой блок (**источник**) внутрь другого блока (**цели**): в экспорте на месте связи окажется источник целиком. Так одну карточку можно поставить в несколько мест и править в одном.

- Источником может быть только корневой блок; один источник можно подключить в сколько угодно мест.
- Связь стоит среди детей цели как обычный ребёнок: у неё свои свойства «как ребёнок» (`flex`, ширина, span) и повтор ×N — они относятся к этому месту, а не к источнику.
- Внутрь связи ничего не вложить. Связь не может стоять на поле сама по себе.
- Циклы запрещены: источник нельзя подключить внутрь самого себя или в блок, который уже стоит внутри источника (в том числе через другие связи).
- Если удалить корневой блок-источник, все связи на него тоже удалятся (`Ctrl` + `Z` вернёт всё вместе).
- Корневой блок, к которому подключены связи, нельзя перетащить внутрь другого блока: связи на него повисли бы. Копию (`Alt` при отпускании) положить в блок можно — исходник остаётся корнем.
- При вставке из буфера (`Ctrl` + `V`) связи на уже удалённые корни выбрасываются из копии, остальное вставляется.
- Старые `.json` со связями (до упрощения) снова открываются вместе со связями.

- **Создать связь:** у каждого корневого блока в конце заголовка (справа от ширины превью) есть кружок-**порт**. Зажмите его и тяните: от порта к курсору идёт пунктирная линия, курсор — прицел. Блок под курсором, куда связь встать может, подсвечивается синим пунктиром, а линия вставки показывает, на каком месте среди его детей она окажется. Блок, куда нельзя (сам источник, его содержимое или блок, который источник уже включает через другие связи), подсвечивается красным, курсор — «нельзя». Отпустите над синим блоком — связь встанет туда и выделится (`Ctrl` + `Z` отменит). Над пустым полем, панелями и красным блоком отпускание ничего не делает, `Esc` отменяет протягивание. Над плашкой целью считается её родитель. У края поля во время протягивания поле само прокручивается.
- **Стрелки:** тонкая стрелка идёт от источника к плашке (от края источника к краю плашки). По умолчанию видны только стрелки **выделенной** связи или **выделенного** источника (синие): на большом документе все стрелки сразу превращаются в паутину. Кнопка «Все стрелки связей» на плашке зума (две стрелки, правее цепочки) показывает стрелки всех связей (серые, у выделенных — синие); выбор запоминается в браузере. Стрелки двигаются вместе с полем и при зуме остаются тонкими; клики проходят сквозь них. Если плашка лежит поверх источника (перекрываются), стрелка не рисуется.
- **Перенести связь за конец стрелки:** выделите связь (или включите все стрелки), наведите на наконечник стрелки (у плашки) — появится кружок, курсор «рука». Зажмите и тяните на другой блок: как при создании, синим подсвечивается допустимая цель с линией вставки, красным — недопустимая. Отпустите — связь переедет туда с тем же источником и прежними свойствами места (`Ctrl` + `Z` вернёт). Пока тянете, старая стрелка скрыта; `Esc` отменяет. Клик по кружку без сдвига выделяет связь. Сменить источник у связи нельзя: удалите её и протяните новую от порта нужного корня.
- **Вынести блок в компонент:** выделите вложенный блок и нажмите «Вынести на канвас» в действиях панели «Свойства» — блок станет корневым справа от своего корня, а на его месте появится связь на него.
- **Плашка на канвасе:** связь видна на месте ребёнка как блок с пунктирной обводкой и штриховкой и подписью `⇢ Имя источника` (имя меняется вместе с подписью источника). Повтор ×N у связи работает как у блока: плашка рисуется N раз.
- **Выделить, двигать, удалить:** плашку выделяют кликом (на поле или в «Слоях»), тянут мышью, переставляют «Выше» / «Ниже», дублируют (`Ctrl` + `D`), копируют и вставляют (`Ctrl` + `C` / `Ctrl` + `V`), удаляют (`Delete`) — как обычный блок. Перетащить что-то внутрь плашки нельзя: над плашкой приёмником становится её родитель, блок встанет рядом с ней.
- **Перейти к источнику:** двойной клик по плашке или кнопка «Перейти к источнику» в панели «Свойства» — источник выделится и окажется в центре поля.
- **Свойства связи:** в заголовке `⇢ Имя источника` и `связь · ребёнок flex/grid`; секции «Связь» (источник и переход к нему) и «Как ребёнок» (`flex`, ширина, span, высота, повтор — для этого места). Секций «Блок» и «Контейнер» у связи нет; подпись связи не редактируется (`F2` и двойной клик не открывают ввод). «На канвас» у связи недоступно.
- **Ширина источника и места:** в секции «Связь» строка «Ширина  источник: 480px / место: 456px» — ширина превью корня-источника и ширина, которую плашка занимает на своём месте (по полю, как бейдж). Кнопка **«Подогнать»** ставит ширину превью источника равной месту, чтобы видеть источник таким, каким он встанет в цель (`Ctrl` + `Z` вернёт). Если ширины совпадают, кнопка недоступна.
- **Живое зеркало:** кнопка-цепочка на плашке зума (рядом с ярлыком подписей). Включённая показывает на месте каждой связи содержимое источника так, как оно встанет в экспорт: раскладка источника в размерах места (связи внутри источника в зеркале остаются плашками, а в экспорте раскрываются). Пунктирная обводка связи остаётся. Содержимое зеркала не редактируется: клик по нему выделяет связь, тянуть — тянет связь; правьте сам источник — зеркала обновятся сразу. Связи внутри источника в зеркале показаны плашками. Выбор запоминается в браузере, в документ и экспорт не попадает. Горячей клавиши нет.
- **«Слои»:** строка связи со значком-цепочкой, именем источника и типом `связь`.
- **Бейдж и путь:** `⇢ Имя источника · связь · Ш×В`; в пути последний сегмент — `⇢ Имя источника`.
- **Создать блок при выделенной связи** (`F`, `G`, шаблон, вставка): новый блок встаёт рядом со связью, в её родителе.

- **В экспорте** связь превращается в содержимое источника с пометкой `компонент «…»` (см. «Экспорт»). Промпт по умолчанию просит ИИ сделать такой компонент один раз и переиспользовать.

## Горячие клавиши ✅

В полях ввода горячие клавиши не срабатывают. Эту же таблицу показывает окно горячих клавиш: откроется по `?` или кнопкой «?» в хедере (рядом с переключателем темы); закрывается `Esc`, крестиком или кликом по фону. Пока окно открыто, клавиши канваса не работают.

| Клавиши | Действие |
|---|---|
| **Блоки** | |
| `F` | Добавить flex-блок (в выделенный или на канвас) ✅ |
| `G` | Добавить grid-блок (в выделенный или на канвас) ✅ |
| `Del` / `Backspace` | Удалить выделенный блок ✅ |
| `Ctrl` + `D` | Дублировать ✅ |
| `Alt` + `↑` / `↓` | Переставить среди соседей ✅ |
| `Ctrl` + `C` / `Ctrl` + `V` | Копировать / вставить ✅ |
| `F2` | Переименовать ✅ |
| **Выделение** | |
| `Esc` | К родителю / снять выделение ✅; во время перетаскивания — отменить его ✅ |
| `Enter` | К первому ребёнку ✅ |
| **История** | |
| `Ctrl` + `Z` | Отменить ✅ |
| `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | Повторить ✅ |
| **Канвас** | |
| `Пробел` + мышь | Двигать поле |
| Средняя кнопка мыши | Двигать поле |
| Колесо / два пальца на тачпаде | Двигать поле (над областью прокрутки — прокрутить её) |
| `Shift` + колесо | Двигать поле по горизонтали |
| `Ctrl` + колесо / щипок | Масштаб к курсору |
| `Ctrl` + `=` / `Ctrl` + `-` | Приблизить / отдалить |
| `Ctrl` + `0` | Масштаб 100% |
| `Shift` + `1` | Вписать всё |
| `Shift` + `2` | Вписать выделенное ✅ |
| **Перетаскивание** | |
| Зажать ЛКМ на блоке и повести (больше 4px) | Начать перетаскивание ✅ |
| Тянуть за заголовок корневого блока | Двигать корневой блок по полю ✅ |
| Отпустить блок над пустым полем | Сделать блок корневым ✅ |
| `Esc` (не отпуская мышь) | Отменить перетаскивание ✅ |
| `Alt` при отпускании (канвас) | Копировать вместо переноса ✅ |
| **Меню документов** | |
| `↑` / `↓` | Выбрать строку ✅ |
| `Enter` | Переключиться на документ ✅ |
| `F2` | Переименовать документ ✅ |
| `Delete` | Удалить документ ✅ |
| `Esc` | Закрыть меню; в режиме правки строки — отменить правку ✅ |
| **Прочее** | |
| `Ctrl` + `E` | Экспорт ✅ |
| `?` | Окно горячих клавиш ✅ |
| `Esc` | Закрыть окно (экспорт, горячие клавиши) ✅ |
